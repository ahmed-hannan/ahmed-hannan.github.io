# Ahmed Hannan — Personal Portfolio

Welcome to the source repository for my personal developer portfolio website, hosted live at [ahmed-hannan.github.io](https://ahmed-hannan.github.io).

## Overview

A high-performance, responsive portfolio showcasing my work across:
- **Artificial Intelligence & Machine Learning**: Multimodal RAG, Computer Vision, Pose Estimation, LLM Cross-Encoders, Autoregressive Generative Models.
- **Full-Stack & Mobile Engineering**: Scalable Web Applications, Cross-Platform Mobile Apps (iOS & Android) with Flutter & React, RESTful Microservices.
- **High-Performance Computing**: GPU Parallelization, CUDA, Tensor Cores, OpenMP, MPI.

## Tech Stack & Design System

- **Frontend**: Semantic HTML5, Modern CSS3 with Custom Design Tokens, ES6+ JavaScript.
- **Theme**: Obsidian Black (`#0a0a0c`), Pure White (`#ffffff`), and Crimson Red (`#ff2a55` / `#ef4444`) accents.
- **Hosting**: GitHub Pages.

## Local Development

Open `index.html` in any modern web browser or serve via a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node / npx
npx serve .
```
